# Epsilon – Built-In Validation Test Report

This report records the results of the 8 built-in validation test cases defined in [`src/ui/nfaToDfa/validationCases.ts`](../src/ui/nfaToDfa/validationCases.ts) and executed through [`runValidationCases()`](../src/ui/nfaToDfa/validationCases.ts) using `nfaToDfa.validate(nfa)` and `nfaToDfa.run(nfa)`.

- **Summary:** **8 of 8 passed** (`ALL PASSED`)
- **Equivalence verification:** For every test case, `runValidationCases()` also verifies that `nfaAccepts(nfa, w) === dfaAccepts(dfa, w)` for **all** strings `w` over the case's alphabet of length $0 \dots 5$ (`Len≤5 agree: Yes`).
- **Canonical state naming:** Inside each DFA state name `{...}`, member NFA states appear in the order of `nfa.states`. Lists of DFA state names and accepting states are compared as sets (order-independent).
